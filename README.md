# 💻 Laptop Price Analysis

## 📌 Project Overview

This project analyzes laptop pricing data to identify the key factors influencing laptop prices. Using Python for data cleaning and exploratory data analysis (EDA), and Power BI for visualization, the project provides actionable insights into pricing trends across different laptop brands and specifications.

---

## 🎯 Business Problem

Laptop prices vary significantly based on hardware specifications and brand reputation. The objective of this project is to understand which features have the greatest impact on pricing and help consumers and businesses make data-driven decisions.

---

## 📂 Dataset

- Dataset: Laptop Specifications Dataset
- Records: 1,300+ laptops
- Features include:
  - Brand
  - Processor
  - RAM
  - Storage
  - GPU
  - Operating System
  - Screen Size
  - Weight
  - Price

## 📈 Key Insights

- Premium brands generally command higher prices.
- RAM and SSD capacity strongly influence laptop pricing.
- Gaming laptops are priced significantly higher than standard laptops.
- Processor generation has a noticeable impact on market value.
- Lightweight ultrabooks often carry premium pricing.
